# 弹弓飞镖

打开即可玩的中文弹弓飞镖小游戏。静态网页，无构建步骤、账号或后台服务。

## 本地预览

1. 在项目目录运行 `python3 -m http.server 4173 --directory dist`。
2. 打开 `http://localhost:4173`。
3. 看到靶盘和下方弹弓即表示加载成功；拉住弹弓向后拖动，松手发射。

运行命令会启动本地预览服务，不会发布网站。按 Ctrl+C 停止。

## 操作与规则

- 鼠标或手指拖动下方弹弓；方向与拉弓偏移相反，拉得越远力度越大。
- 也可聚焦游戏画布，方向键调整拉弓，空格或 Enter 发射，Escape 取消。
- 头像靶心50分；包括红色外框在内的其他靶盘区域10分；脱靶0分。
- 90%及以上力度命中会碎裂；普通命中累计12支会掉落。碎裂优先。
- 两秒后自动换盘并保留得分；“换个靶盘”保留得分，“重新开始”清空成绩。
- 声音由浏览器在首次操作后启用，可随时关闭。

## 验证

Node.js 20或更高版本运行 `npm test`。测试覆盖实际弹道碰撞、弱力落地、力度边界、积镖掉落、破坏优先级和成绩保留。

`dist/physics.js` 管理飞行和规则；`dist/game.js` 管理画面、输入和动画。轨迹提示与碰撞共用同一套飞行计算。所有素材均在网站内提供。

## 托管

`.openai/hosting.json` 保存对应 Sites 项目标识，静态发布目录为 `dist`。使用 Sites 插件的源码同步、打包、保存版本和部署流程更新。公开发布会上传代码与头像素材。
