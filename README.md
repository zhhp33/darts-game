# 弹弓飞镖

打开即可玩的中文弹弓飞镖小游戏。静态网页，无构建步骤、账号或后台服务。

## 本地预览

1. 在项目目录运行 `python3 -m http.server 4173 --directory dist`。
2. 打开 `http://localhost:4173`。
3. 看到靶盘和下方弹弓即表示加载成功；拉住弹弓向后拖动，松手发射。

运行命令会启动本地预览服务，不会发布网站。按 Ctrl+C 停止。

## 操作与规则

- 鼠标或手指拖动下方弹弓；方向与拉弓偏移相反，拉得越远力度越大。
- 直向后拉时，65—70%力度落在靶心附近；70—99%继续平滑上移。100%按弹弓发射方向分成上、下、左、右及四个斜向扇区，在对应扇区内随机命中。往下拉朝上射，往左拉朝右射；满力仍可拖动调整方向，但不显示虚线轨迹；松手后按这次方向随机命中对应扇区。非满力的虚线与实际飞行共用同一套弹道。第四次满力命中仍然碎盘，这一发得100分。
- 也可聚焦游戏画布，方向键调整拉弓，空格或 Enter 发射，Escape 取消。
- 头像靶心50分，提示“特大杯”；内盘10分，提示“大杯”；红色外框5分，提示“中杯”；脱靶0分。电脑和手机提示均跟随靶盘下缘，避免遮住黑色盘面。
- 力度范围0—100%；同一靶盘第一次满力命中出现小裂痕，第二次在当次落点新增更大的裂痕，第三次新增更大的裂痕，第四次碎裂。已有裂痕保持原来的尺寸和形状；非满力命中和脱靶不累计破坏次数。靶盘不显示数字。
- 命中提示以大字显示杯型、小字显示加分。每次100%力度的飞镖落点播放一声“啪”；碎盘这一发只加100分，替代普通命中分数，大字提示“罗老师，别这样”，小字提示“+100”，播放用户确认的 TRP 原录音前三下掌声，起音间隔约0.27秒，整段约0.91秒，响度匹配原有碎盘音效。声音关闭时保持静音。
- 力度大于60%时飞镖笔直插住，靶盘短暂震动；60%及以下飞镖下垂，靶盘不震动。
- 拖动范围包含绳子和飞镖的安全边距，不会超出游戏背景。
- 盘上飞镖数量显示为“0/12”等格式，数字紧接“盘上飞镖”。插满12个时，大字提示“理解万岁！”，沿用“罗老师，别这样”的样式，并以小字显示当次加分，同时播放1.8秒的观众欢呼与掌声，音量为原淡出试听的八分之一，结尾0.6秒平滑淡出。关闭声音、重新开始或离开页面时停止欢呼。
- 两秒后自动换盘并保留得分；碎盘及插满12个掉落后都会自动切换到下一种头像样式。“换个靶盘”也会轮换经典、访谈、大头三种头像。“重新开始”清空成绩。
- 每块新靶盘清空飞镖、满力次数和裂痕。大于60%的飞镖轮换斜插、尾翼正对镜头、透视短轴三种姿态；60%及以下保持下垂。
- 射中背景墙的脱靶飞镖留下坑；落地不留墙坑。坑以世界坐标保存在当前浏览器的本地存储中，换盘、重开、刷新及调整屏幕尺寸后仍保留；清理浏览器网站数据会删除这些坑。
- 声音在首次操作时启用。页面加载时只预先下载和解码音效，第一次触碰时才创建播放环境；iPhone Safari 在手指刚碰到屏幕时播放一个听不见的空白片段来启用声音，避免拖动后的松手无法解锁声音。声音启动稍慢时会等待后播放，切回页面后的下一次操作会尝试恢复声音，可随时关闭。

## 验证

Node.js 20或更高版本运行 `npm test`。测试覆盖实际弹道碰撞、弱力落地、力度边界、积镖掉落、破坏优先级和成绩保留。

`tests/audio-startup.mjs` 使用与浏览器冒烟检查相同的运行参数，覆盖手机松手解锁、Safari拖动不算点击时的首次启用、首次音效等待、声音中断恢复、音效慢加载及失败重试、静音和重开时取消待播声音。

`dist/physics.js` 管理飞行和规则；`dist/game.js` 管理画面、输入和动画；`dist/fracture.js` 从实际命中点生成不规则破碎块。轨迹提示与碰撞共用同一套飞行计算。所有素材均在网站内提供。

两张新增头像通过内置 imagegen 工具去背景，提示要求保留原表情、眼镜、衣领和人物比例，访谈图同时移除麦克风装置；大头图保留大头比例。成品在 `dist/assets/portrait-interview.png` 和 `dist/assets/portrait-caricature.png`，采用透明背景。

默认头像直接采用用户提供的714×714方形图片，保存为 `dist/assets/portrait-classic-square.png`。三种头像使用相同显示框，并等比例缩放。

## 托管

`.openai/hosting.json` 保存对应 Sites 项目标识，静态发布目录为 `dist`。使用 Sites 插件的源码同步、打包、保存版本和部署流程更新。公开发布会上传代码与头像素材。
