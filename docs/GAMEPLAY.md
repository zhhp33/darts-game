# 弹弓飞镖 · 玩法与规则详解

> 这里记录游戏的完整操作与规则细节。快速上手请看 [README](../README.md)。

## 操作与规则

- 每次打开页面先点击“开始”，在这次点击中启用声音。弹弓用约0.75秒从下方向上浮入，完成后才允许发射；重新开始和换盘无需再次点击“开始”。减少动态效果开启时只做短暂淡入。
- 鼠标或手指拖动下方弹弓；方向与拉弓偏移相反，拉得越远力度越大。
- 直向后拉时，65—70%力度落在静止靶心附近；70—99%继续平滑上移。100%按弹弓发射方向分成上、下、左、右及四个斜向扇区，在对应扇区内随机确定弹道。往下拉朝上射，往左拉朝右射；满力仍可拖动调整方向，但不显示虚线轨迹。靶盘移动时按飞镖到达那一刻的实际位置判定，因此满力也可能脱靶。非满力的虚线与实际飞行共用同一套弹道。第四次满力命中会碎盘，这一发得100分；第四块靶盘若未先碎裂，则累计命中六次后甩飞。
- 也可聚焦游戏画布，方向键调整拉弓，空格或 Enter 发射，Escape 取消。
- 头像靶心50分，提示“特大杯”；内盘10分，提示“大杯”；红色外框5分，提示“中杯”；脱靶0分。电脑和手机提示均跟随靶盘下缘，避免遮住黑色盘面。
- 力度范围0—100%；同一靶盘第一次满力命中出现小裂痕，第二次在当次落点新增更大的裂痕，第三次新增更大的裂痕；所有阶段的第四次满力命中都会碎裂，第四块靶盘若未先碎裂，则累计六次有效命中后甩飞。已有裂痕保持原来的尺寸和形状；非满力命中和脱靶不累计破坏次数。靶盘不显示数字。
- 命中提示以大字显示杯型、小字显示加分。每次100%力度的飞镖落点播放一声“啪”；碎盘这一发只加100分，替代普通命中分数，大字提示“罗老师，别这样”，小字提示“+100”，播放用户确认的 TRP 原录音前三下掌声，起音间隔约0.27秒，整段约0.91秒，响度匹配原有碎盘音效。声音关闭时保持静音。
- 力度大于60%时飞镖笔直插住，靶盘短暂震动；60%及以下飞镖下垂，靶盘不震动。
- 拖动范围包含绳子和飞镖的安全边距，不会超出游戏背景。
- 盘上飞镖数量显示为“0/12”等格式，数字紧接“盘上飞镖”，下方12格绿色进度条随盘上飞镖数量逐格点亮，换盘后归零。插满12个时，大字提示“理解万岁”，沿用“罗老师，别这样”的样式，并以小字显示当次加分，同时播放1.8秒的观众欢呼与掌声，音量为原淡出试听的8%，结尾0.6秒平滑淡出。关闭声音、重新开始或离开页面时停止欢呼。
- 两秒后自动换盘并保留得分；碎盘及插满12个掉落后都会自动切换到下一种头像样式。“换个靶盘”也会轮换经典、访谈、大头三种头像。“重新开始”清空成绩。
- 每块新靶盘清空飞镖、满力次数和裂痕。大于60%的飞镖轮换斜插、尾翼正对镜头、透视短轴三种姿态；60%及以下保持下垂。
- 射中背景墙的脱靶飞镖留下坑；落地不留墙坑。坑以世界坐标保存在当前浏览器的本地存储中，换盘、重开、刷新及调整屏幕尺寸后仍保留；清理浏览器网站数据会删除这些坑。
- 页面加载时只预先下载和解码音效，在“开始”按钮的真实点击事件中创建播放环境、启动空白音频并恢复声音，再进入弹弓入场动画。开启声音失败时保留“开始”入口以便重试，也可以关闭声音后开始；保存的静音偏好继续生效。切回页面后的下一次操作会尝试恢复声音，可随时关闭。

## 摇摆与锤子彩蛋

- 真正拉到100%时，弹弓和皮筋出现约1—2像素的细抖，不改变瞄准或弹道。支持震动的设备每次拉弓只短震一次；开启“减少动态效果”时取消细抖和震动。
- 每轮第一块靶盘静止。碎盘、插满掉落或手动甩飞后，下一块分别以6°、14°、28°的幅度左右摇摆，每次往返约两秒。第四块持续摇摆，不再按时间自动甩飞；任意力度累计有效命中六次才甩飞，脱靶不计数；如果先累计四次满力命中，仍然提前碎盘，同一发同时满足条件时优先碎盘。甩飞后恢复静止靶盘并重启轮次；第六次命中按正常落点计分，甩飞不额外加分。手动换盘保留当前摇摆阶段，“重新开始”清零。
- 鼠标或手指在靶盘上拖动超过8像素即可拨盘；松开后额外摇摆至少明显往返约三次（约六秒），再缓慢衰减至停止。最近约100毫秒的速度达到每秒四个靶盘直径，且滑过至少15%的直径时，会把靶盘甩飞。拖动取消、失去捕获或切走页面不会误领锤子。
- 轻点头像出现闪光和“获得锤子 ×1”，再单独点击锤子领取。滑动头像不会领取；已移除底部圆圈图标和整段射击引导。
- 领取后进入无限锤击模式，暂停射镖、自动摇摆和换盘。靶盘每锤80分；绳子、声音按钮和顶部品牌区域每锤666分；其他区域每锤40分。同一物件重复砸击仍有反馈，但破坏进度只计一次。
- 砸中绳子或钉子时，靶盘此前被锤击至少10次就直接碎落；不足10次则整盘掉到底部，继续敲一下才碎。碎块落地立即消失并释放，不保留可点击碎块；原来悬空的整盘区域不再算靶盘。锤击次数独立于计分，计分板损坏后仍会累计。砸声音按钮会立即停止全部声音；砸计分板先加40分，之后所有砸击都不再计分或显示加分。重开、换盘按钮掉落后不再响应悬停高亮；顶部logo与“弹弓飞镖”文字共用一个触发区域，敲中任一处或中间空隙，图标沿抛物线掉到底部并轻弹，文字同时歪挂在顶部；整组每锤666分，破坏进度只计一项。力度条爆表并固定100%；弹弓顺着木纹裂开，皮筋松脱。
- 靶盘、绳子、声音、计分板、重开、换盘、顶部品牌、力度条、弹弓九类物件各破坏一次（弹弓需两下），最后一锤同时击碎锤子，随后出现冒热气的咖啡和“歇会儿再砸”。背景不计入完成条件；剩余不超过三类时，未破坏物件轻闪提示。
- 点击“歇会儿再砸”恢复页面、分数和摇摆轮次，声音恢复到领取前的开关状态。锤击损坏不保存到下次刷新；原有墙坑仍按原规则保留。减少动态效果时缩短掉落、甩飞和碎锤到咖啡的等待时间。
