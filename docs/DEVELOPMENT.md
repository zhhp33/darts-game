# 弹弓飞镖 · 开发说明

> 这里记录测试、代码结构和部署的细节。快速上手请看 [README](../README.md)。

## 验证

Node.js 20或更高版本运行 `npm test`。测试覆盖实际弹道碰撞、弱力落地、力度边界、积镖掉落、破坏优先级和成绩保留。

`tests/audio-startup.mjs` 使用与浏览器冒烟检查相同的运行参数，覆盖“开始”的首次真实点击、声音启用、弹弓上浮、入场期间禁止发射、静音、启用失败重试和减少动态效果。可用第五个参数 `webkit` 运行对应引擎检查；声音原生流程不再用人为定义的触摸解锁规则代替真机验证。

`tests/mayhem.test.js` 覆盖移动靶盘的命中与本地坐标、摇摆轮次、甩飞门槛、不同破坏顺序和计分冻结。`tests/mayhem-smoke.mjs` 使用与浏览器冒烟检查相同的前三个参数（依赖目录、预览URL、截图目录），覆盖满力手感、拨盘持续时间、第四块六次命中甩飞、桌面/触摸/320像素小屏、锤击次数分支、整盘落地再敲碎、碎块落地清理、图标抛物线与轻弹、图标标题分离、十类物件、碎锤、咖啡重开与减少动态效果。实际手机是否震动仍取决于设备、浏览器和系统设置，自动化检查只验证触发与降级逻辑。

`dist/physics.js` 管理飞行和规则；`dist/game.js` 管理画面、输入和动画；`dist/motion.js` 提供画面与命中共用的靶盘运动；`dist/mayhem.js` 和 `dist/mayhem-view.js` 分别管理锤击规则与页面破坏表现；`dist/fracture.js` 从实际命中点生成不规则破碎块及不同材质的裂纹。所有素材均在网站内提供，无新增运行依赖。

两张新增头像通过内置 imagegen 工具去背景，提示要求保留原表情、眼镜、衣领和人物比例，访谈图同时移除麦克风装置；大头图保留大头比例。成品在 `dist/assets/portrait-interview.png` 和 `dist/assets/portrait-caricature.png`，采用透明背景。

默认头像直接采用用户提供的714×714方形图片，保存为 `dist/assets/portrait-classic-square.png`。三种头像使用相同显示框，并等比例缩放。

## 托管

`.openai/hosting.json` 保存对应 Sites 项目标识，静态发布目录为 `dist`。使用 Sites 插件的源码同步、打包、保存版本和部署流程更新。公开发布会上传代码与头像素材。
